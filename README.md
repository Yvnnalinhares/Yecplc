# Yecplc — skills de Instagram para a loja

Skills do Claude Code para criar posts, Reels, Stories, carrosséis e conversas de venda no Instagram da loja.

## Como usar
1. Abra este repositório no Claude Code.
2. Preencha `marca/marca.md` (ou peça: "me ajuda a preencher a marca da loja").
3. Peça o que precisa, por exemplo:
   - "Planeja os posts da semana"
   - "Faz um carrossel sobre a nova coleção"
   - "Escreve o roteiro de um Reel mostrando o produto X"
   - "Monta a DM pra quem comentar EU QUERO"

As instruções gerais (português, foco em venda, onde salvar arquivos) estão em `CLAUDE.md`.

O conector opcional da Fliqr (dados reais da conta e automação de DM) não está configurado; as skills funcionam com o que você colar na conversa.
